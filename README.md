# Свои люди — лендинг

Одностраничный лендинг личной CRM «Свои люди». Одно действие — перейти в приложение по кнопке «Добавить первый контакт».

Стек: Astro + Tailwind CSS 4, статичная страница. Макет и тексты — в `design/`.

## Команды

```sh
pnpm install   # поставить зависимости
pnpm dev       # локальный сервер: http://localhost:4321
pnpm build     # собрать статику в dist/
```

## Как менять тексты

Все тексты страницы — в одном файле: `src/content/landing.md`. Файл `design/content/landing.ru.md` — архив согласованных текстов из макета, сайт его не читает.

1. Запусти `pnpm dev` и открой http://localhost:4321.
2. В `src/content/landing.md` меняй **только текст внутри кавычек** `"…"`. Названия полей слева от двоеточия не трогай.
3. Сохрани файл — страница в браузере обновится сама.

Правила:

- `[квадратные скобки]` — фраза под жёлтым мазком (в заголовке первого экрана и в последнем блоке). Скобки на странице не видны. Фраза под мазком не переносится — делай её короткой, 2–3 слова.
- `~` — неразрывный пробел: слова по обе стороны не разъедутся на разные строки (`за~10~секунд`).
- Кавычки-«ёлочки» внутри текста — можно. Прямые кавычки `"` внутри текста — нельзя, они закрывают строку.
- Пункты списков начинаются с `- ` и отступа как у соседних строк. В «Как это устроено» ровно 3 шага — у каждого свой рисунок.

Если что-то сломалось, страница покажет ошибку с названием файла и поля — верни как было или напиши мне.

## Картинка для превью ссылки (OG)

`public/og.png` — картинка 1200×630, которую показывают Telegram, WhatsApp и соцсети под ссылкой на лендинг. Собирается из заголовка и стопки карточек первого экрана.

Если поменялся заголовок или подпись — пересобери картинку:

1. Запусти `pnpm dev`. Посмотреть, как будет выглядеть: http://localhost:4321/og-image (эта страница есть только на локальном сервере, на сайт не попадает).
2. Выполни `pnpm og` — картинка перезапишется в `public/og.png`.

## Не забыть

- **Адрес приложения.** Сейчас обе кнопки ведут на заглушку `#`. Когда будет адрес приложения, добавить в `.env` строку
  `PUBLIC_APP_URL=https://app.<мой домен>` и пересобрать. Для сборки в GitHub Actions ту же переменную нужно будет передать в workflow.
  Код: `src/components/CtaButton.astro`.
- **Адрес лендинга для превью.** Соцсети берут картинку только по полному адресу. Когда будет домен, добавить в `.env` строку
  `PUBLIC_SITE_URL=https://<мой домен>` (и передать её в GitHub Actions). До этого превью ссылки будет без картинки.
