# Лендинг «Свои люди» — бриф для разработки

Статичный одностраничный лендинг личной CRM «Свои люди». Одно целевое действие — перейти в приложение по кнопке «Добавить первый контакт».

Эта папка — материалы для разработки. Сверстай страницу по ним на **Astro + Tailwind CSS 4**, статическая сборка (`output: 'static'`), без JS-фреймворков и клиентского JS.

## Что в папке

| Путь | Что это | Как использовать |
|---|---|---|
| `design/reference-mobile.html` | Эталон мобильной версии (ширина 390 px) | Открыть в браузере, сверять один в один |
| `design/reference-desktop.html` | Эталон десктопной версии (1440 px, контент 1180 px) | То же |
| `design/tokens.json` | Исходные токены дизайн-системы | Справочно; рабочие токены уже в `src/styles/global.css` |
| `content/landing.ru.md` | Утверждённые тексты | Источник копирайта. Тексты не переписывать |
| `src/styles/global.css` | Tailwind 4: `@theme` с токенами + базовые стили | Положить в проект как есть |
| `src/assets/*.svg` | Логотип-знак, мазок-маркер, иконки | Инлайнить в Astro-компоненты (цвета через `currentColor`, где указано) |
| `public/favicon.svg` | Фавикон (знак) | Положить в `public/` |

Эталонные HTML — главный источник правды по раскладке, размерам и отступам. Все стили там инлайновые: перенеси их в утилиты Tailwind, используя токены из `@theme`. Не копируй инлайн-стили в компоненты. `min-height` у корневого блока эталонов (4420 / 3560 px) — это размер макета, а не страницы: в вёрстку не переносить, высота страницы — по контенту.

## Стек и настройка

- Astro (последняя стабильная), `output: 'static'`.
- Tailwind CSS 4 через `@tailwindcss/vite` (не `@astrojs/tailwind` — он для v3). Конфига `tailwind.config.js` нет, все токены — в `@theme` в `global.css`.
- Шрифты self-hosted через Fontsource: `@fontsource-variable/manrope` и `@fontsource-variable/space-grotesk`. Импорт в layout. Google Fonts по ссылке не подключать.
- `<html lang="ru">`.
- Адрес приложения — из переменной окружения `PUBLIC_APP_URL` (в `.env.example` положить заглушку `https://app.example.com`). Обе кнопки ведут туда.

### Важно про шрифты: в Space Grotesk нет кириллицы

Space Grotesk покрывает только латиницу (+ вьетнамский). Русский текст, набранный им, на самом деле рисуется следующим шрифтом в стеке. Поэтому стек дисплейного шрифта: `"Space Grotesk Variable", "Manrope Variable", system-ui, sans-serif` — кириллица заголовков падает на Manrope, а цифры («01», «10») и латиница («example.com») остаются в Space Grotesk. Это осознанное решение, не баг. Не подключай кириллический сабсет Space Grotesk — его не существует.

## Структура страницы

Порядок блоков строго такой (тексты — в `content/landing.ru.md`):

1. **Header** — знак + «Свои люди.» (точка цветом `accent`). Без навигации, без входа.
2. **Hero** — плашка-пилюля «Записная книжка своих людей», `h1` «Помни тех, кого знаешь лично» (мазок под «знаешь лично»), подзаголовок, кнопка, стопка карточек контакта (мокап).
3. **Проблема** — подпись «Знакомо?», `h2`, три пункта с иконками, финальная строка коричневым.
4. **Решение** — светлая подложка `surface` во всю ширину; подпись «Как это устроено», `h2`, абзац; три шага с номером в золотом круге и мини-мокапом (список контактов → форма → поиск + заметка).
5. **Выгоды** — подпись «Что даёт», `h2` «Что изменится», пять карточек с декоративными номерами 01–05; карточка 03 выделена (`accent-soft` фон, `aurora-gold` рамка и номер).
6. **CTA** — карточка по центру: знак, `h2` «Начни с одного человека» (мазок под «одного человека»), подзаголовок, та же кнопка.
7. **Footer** — знак + «Свои люди.» слева, «Записная книжка своих людей» справа.

Подписи «Знакомо?», «Как это устроено», «Что даёт» — дизайнерские, их нет в исходном тексте, но они утверждены.

## Компоненты (рекомендуемая нарезка)

```
src/
  layouts/Base.astro          — <head>, шрифты, meta, global.css
  components/
    Logo.astro                — знак + название; prop size: 'header' | 'footer'
    CtaButton.astro           — <a href={PUBLIC_APP_URL}> со стрелкой; prop fullWidth
    Marker.astro              — оборачивает слот: <span class="relative inline-block whitespace-nowrap z-0">…<svg>мазок</svg></span>
    SectionLabel.astro        — линия 30×2 `teal` + UPPERCASE-подпись
    ContactCardStack.astro    — стопка из 2 повёрнутых подложек + передняя карточка
    Hero.astro, Problem.astro, Solution.astro, Benefits.astro, Cta.astro, Footer.astro
  pages/index.astro
```

Кнопка — один компонент с одним текстом в обоих местах. Мокапы (стопка карточек, мини-список, форма, поиск) — статичная разметка с `aria-hidden="true"` на декоративных частях; у стопки в hero — `role="img"` и `aria-label="Пример карточки контакта"`. В мокапах никаких `<input>`/`<button>` — только `span`/`div`, это картинка, а не интерфейс.

## Адаптив

- Mobile-first. Эталон мобильной — 390 px, боковой отступ 20 px.
- Боковой отступ страницы: `clamp(20px, 5vw, 52px)`. Контент — `max-w-content` (1180 px) по центру.
- Десктопная раскладка — от `lg` (1024 px):
  - Hero: две колонки, текст слева, стопка карточек справа (макс. ширина 470 px), `gap` 64 px. Кнопка по ширине текста.
  - Проблема: три карточки в ряд, иконка над текстом.
  - Решение: `h2` слева, абзац справа (выровнены по нижнему краю); три шага в ряд, мокапы прижаты к низу карточки (`mt-auto`).
  - Выгоды: flex-wrap, `basis` ~340 px, `grow` — получается 3 + 2.
- Между 390 и 1024 — промежуточные состояния: сетки по `auto-fit/minmax`, как в эталоне; главное, чтобы ничего не ломалось и не появлялось горизонтального скролла.
- Мобильная: кнопки во всю ширину (высота 56 px), в пунктах «Проблемы» иконка слева от текста.

## Детали, которые легко потерять

- **Мазок-маркер** (`src/assets/marker.svg`): SVG `viewBox="0 0 300 44"`, `preserveAspectRatio="none"`, абсолютно под текстом: `left: -8px; width: calc(100% + 18px); bottom: -2px; height: .62em` (на десктопе −10px / +22px / .6em), `rotate(-1.6deg)`, `z-index: -1` внутри родителя с `z-index: 0`. Цвет заливки и обводки — `#eed197` (токен `marker`), прозрачность .95. Фраза под мазком не переносится (`whitespace-nowrap`).
- **«за 10 секунд»** — неразрывные пробелы: `за&nbsp;10&nbsp;секунд`, чтобы «10» не висело в конце строки.
- **Номера 01–05** в выгодах декоративные (`aria-hidden`), у заголовка карточки `padding-right`, чтобы не наезжать на номер; между заголовком и текстом 18 px.
- **Бирюза — второй акцент, ~10% и точечно.** Золото отмечает главное (кнопка, мазок, точка в названии, номера шагов, свечения), бирюза — «живое»: точка в плашке hero и линии подписей секций — `teal`; рамка и иконка поля поиска, курсор и подпись «Новая заметка» в мокапе шага 3, фокус — `teal-deep`. Кольцо в логотипе-знаке — `teal-deep` (#166f74) (золотой круг + тёмно-бирюзовое кольцо). Бирюзу не ставить на кнопку, мазок, точку в названии и свечения — они золотые. Бирюзовым (`teal`, 2.5:1) не набирать текст.
- **Свечение (aurora)** за шапкой и hero — три размытых радиальных градиента (см. эталон). Только там; больше градиентов на странице нет, кроме мягкого свечения в углах CTA-карточки.
- **Стопка карточек**: задняя подложка `surface-2`, `rotate(-3.5deg)`; средняя `accent-soft`, `rotate(2.5deg)`; передняя `surface`, рамка `line`, тень `shadow-card`.
- Аватар в карточке — круг с инициалами, не фото.

## Состояния и движение

- Кнопка: hover — фон `accent-deep`, подъём на 3 px (`translateY(-3px)`), `transition: .35s cubic-bezier(.34,1.4,.5,1)`.
- Focus-visible: обводка 2 px `teal-deep` (`#166f74`, 5.2:1 на фоне), offset 3 px.
- Выделение текста: фон `accent`, текст `ink`.
- Всё движение выключается при `prefers-reduced-motion: reduce`.

## Доступность

- Один `h1`, по `h2` на секцию, `h3` в карточках выгод.
- Пункты проблемы — `<ul>`, шаги — `<ol>`.
- Текст на кнопке — `ink` на `accent` (5.1:1). Белый на `accent` не использовать (1.8:1).
- Цвет `accent` как цвет текста — только декоративно (точка в названии). Акцентный тёплый текст — `brown`.
- Иконки и мазок — `aria-hidden="true"`.

## Ограничения из брифа (не нарушать)

- Только светлая тема. Тёмную тему, неоновые/холодные цвета не добавлять.
- Не рисовать вход/регистрацию, напоминания, уведомления, импорт — этого в продукте нет.
- В мокапах — только выдуманные имена и данные (как в эталоне; телефоны 900-й серии, почта на `example.com`).
- Никаких стоковых фото людей и иллюстраций.
- Без эмодзи и восклицательных знаков.
